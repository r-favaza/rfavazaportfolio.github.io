Interactive Freshman Design Expo Map

A basic python application built using OpenPyXL and PyQT to offer users project information about the projects available ate the freshamn design expo.

My Part: For this project, I was in charge of getting the UI of the project linked to the GPIO component, a physical map with LED lights showing the floor and section of the searched project. This proved more complicated than expected, due to some harware limitations associated with the Raspberry Pi. Once I realized that the Raspberry Pi would not interact correctly with the Program, I created a "duct tape" style workaround, in which the project's information was displayed on a 2nd monitor, and a user would have to manually ytpe in a code for the projects floor and section to get the LED map to light up
